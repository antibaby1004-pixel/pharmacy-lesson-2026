공식 영상은 0:40–3:23 구간(3분)만 연결합니다. 영어 원음입니다. ⚙ 설정 → 자막 → 자동 번역 → 한국어를 선택하세요. 자동자막의 의학용어는 부정확할 수 있습니다. 해외 적응증·지원제도는 국내 기준과 다릅니다.

YouTube에서 0:40부터 보기
시청 안내 · 근거

기전 영상은 0:40–3:23, 자가주사 영상은 1:30–4:40 구간을 연결합니다. 외부 YouTube 링크로 열 경우에는 지정 종료 시점에 직접 돌아와 주세요. 한국어 슬라이드 설명은 기본 1.15배속이며, YouTube 영상은 원래 속도로 재생합니다. 공식 YouTube 영상과 자체 한국어 설명을 연결한 온라인 재생본입니다. 하나의 MP4 파일이 아니며 인터넷 연결이 필요합니다. 브라우저 정책에 따라 장면 전환 시 재생 버튼을 한 번 더 눌러야 할 수 있습니다.

공식 영상은 다운로드·재편집하지 않았습니다. YouTube의 재생 화면과 조작 기능을 그대로 사용합니다. 한국어 자막 우선과 최소 크기를 설정했습니다. 원본 자막 제공 여부에 따라 자동 번역을 직접 선택해야 할 수 있습니다. 별도 한국어 더빙은 포함하지 않았습니다.

자가주사 파트는 사용자가 지정한 시연 영상의 1:30–4:40 구간입니다. 영상 직전에 1회용 펜·보관 조건을 안내합니다. 배포 전 실제 입고 펜·최신 동봉 설명서, 원내 문의처·폐기 절차를 대조하세요.
